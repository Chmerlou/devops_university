Конфигурация виртуальной машины devops-vm
1. Параметры машины
Объём оперативной памяти: 2048 МБ
Количество ядер процессора: 2
Объём дискового накопителя: 25 ГБ (динамически расширяемый)
Тип ОС: Ubuntu Server 26.04.1 LTS (64-bit)
Средство виртуализации: Oracle VM VirtualBox 7.x
2. Сетевые интерфейсы
Интерфейс	Тип адаптера	IP-адрес	Назначение
enp0s3	NAT	10.0.2.15/24	Доступ гостевой системы в Интернет
enp0s8	Host-only	192.168.56.101/24	Доступ с хостовой системы к гостевой
3. Правило проброса портов
Имя правила	Протокол	Хост: порт	Гость: порт	Назначение
ssh	TCP	127.0.0.1:2222	0.0.0.0:2222	Доступ к SSH через NAT-адаптер
4. Учётные записи
Имя	UID	Группы	Способ аутентификации
student	1000	student, sudo	Парольная (для восстановления)
devops	1001	devops, sudo	Ключевая (ed25519, ~/.ssh/devops_vm)
5. Служба SSH
Порт: 2222
Конфигурационный файл: /etc/ssh/sshd_config.d/99-hardening.conf
Резервная копия: /etc/ssh/sshd_config.backup
Изменённые директивы:

Директива	Значение	Назначение
Port	2222	Нестандартный порт SSH
PermitRootLogin	no	Запрет входа от имени root
PasswordAuthentication	no	Отключение парольной аутентификации
PubkeyAuthentication	yes	Разрешение аутентификации по ключу
PermitEmptyPasswords	no	Запрет пустых паролей
MaxAuthTries	3	Ограничение попыток аутентификации
LoginGraceTime	30	Время на аутентификацию (сек)
AllowUsers	devops	Список разрешённых пользователей
X11Forwarding	no	Запрет перенаправления X11
ClientAliveInterval	300	Интервал проверки активности клиента (сек)
ClientAliveCountMax	2	Максимальное число проверок
Socket activation отключён, используется ssh.service.

6. Правила межсетевого экрана
Политики по умолчанию:

incoming: deny
outgoing: allow
Правила:

Порт	Действие	Комментарий
2222/tcp	LIMIT	SSH rate-limited (макс. 6 соединений за 30 сек)
80/tcp	ALLOW	HTTP (для практической работы №6)
443/tcp	ALLOW	HTTPS
Логирование: medium (записи в /var/log/ufw.log).

7. Снимки состояния
Наименование	Момент создания	Содержание
01-clean-install	После установки ОС и обновления пакетов	Чистая система, оба адаптера настроены, SSH-сервер установлен
02-keys-configured	После выполнения задания 1	Создан пользователь devops, настроен вход по SSH-ключу, конфиг ~/.ssh/config
03-ssh-hardened	После выполнения задания 2	SSH на порту 2222, пароли отключены, root запрещён
